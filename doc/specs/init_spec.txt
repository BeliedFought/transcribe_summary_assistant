# Исходные требования к проекту (свободная форма)

Проект: транскрибация и саммаризация аудио/видео.

- Загрузка фаилов через папку input (audio/, video/ - подпапки)
- Вывод результатов - папка output
- Локальная Ollama доступна (можно использовать для обработки)
- Возможность использовать API DeepSeek
- Пользователь положил фаил -> запустил скрипт -> скрипт обработал -> результат в output
- Каждая сессия - отдельная папка в data
- Каждая сессия уникальна даже если контент одинаковыи
- В data хранить метаданные и текстовые результаты
- В output копировать результат
- Данные хранить в SQLite в папке проекта
- Язык: русский
- GPU с CUDA доступна
- CLI-скрипты (без меню)
